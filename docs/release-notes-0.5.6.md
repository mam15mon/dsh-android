DSH 安卓 0.5.6

- 新增 WorkBuddy / WorkBuddy AI 模型服务，支持浏览器登录和 API Key，并补齐请求适配，修复测试通过但正式对话报 400 的问题。
- 模型测试改为逐个测试勾选项，分别显示通过、失败和未测试结果，不再自动换成其他模型或遇到首个成功就停止。
- 修复 Markdown 表格长文本截断，支持完整换行和宽表横向滚动。
- 修复 Responses API 的加密推理状态和工具调用续接，保留处理中与最终回答的消息阶段；支持协议自动识别和输出上限字段兼容。
- 新增应用内本地文件预览与文件链接打开，完善存储操作保护。

升级提醒：安装包 ID 仍为 com.dsh.android，可保留数据覆盖升级。内部组件名称已调整，升级后请重新开启无障碍服务；默认助手、快捷设置磁贴及桌面快捷入口如已配置，也需重新选择或添加。
